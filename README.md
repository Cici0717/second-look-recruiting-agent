# 再遇 Second Look · 面试后人才转推 Agent

面向企业校招 HR 的 EHR 内嵌工作台概念 Demo。围绕“原岗位不匹配，但面试中存在其他能力证据”的候选人，帮助 HR 整理证据、复核岗位并审核沟通内容。

**这是纯前端交互原型：所有候选人与岗位均为虚构，AI 建议采用预置输出，不调用真实模型，不发送真实邮件。**

## 产品思路

首版聚焦减少 HR 查找岗位、整理面评和准备转推沟通的成本。面试官提供明确推荐意愿，系统整理建议，HR 保留岗位选择与对外沟通的最终确认权。实际提效与转化收益需要后续业务验证。

## 演示流程

1. **面评确认**：查看原岗位结论、面试官推荐意愿与简历、面试证据。
2. **岗位复核**：查看一句话内部摘要、岗位匹配依据、待确认事项，展开原始证据。
3. **沟通审核**：选择是否附反馈、是否附岗位邀请，编辑文案并实时预览；确认当前版本后模拟发送。
4. **候选人视角**：查看模拟沟通和后续选择，用于讲解闭环，不代表完整候选人工作台。

## 五个模拟案例

| 案例 | 场景 | 展示重点 |
| --- | --- | --- |
| TC01 | AI 产品 → B 端应用 | 企业应用证据不等于平台能力证据 |
| TC02 | C 端产品 → 产品运营 | 岗位缺人不能覆盖 SQL 等关键证据缺口 |
| TC03 | AI 算法 → 数据评测 | 区分已有能力与待核实事项 |
| TC04 | 平台产品 → 技术项目 | 多个合理岗位选择，供需仅辅助合格岗位排序 |
| TC05 | 证据不足，暂不转推 | 允许空推荐，推荐意愿不明确时不强推 |

支持岗位关闭、意向城市不符等异常演示；修改已确认内容后需要重新确认；重复发送被拦截；发送时保留独立快照和演示记录。状态保存在当前浏览器本地，可重置案例。

## 本地运行

需要 Node.js，无第三方依赖：

```bash
node serve.mjs
```

打开 http://127.0.0.1:4187 。也可直接打开 `dist/index.html`。

```bash
node test-core.cjs
```

13 项核心逻辑检查覆盖证据引用、空推荐、供需排序、确认失效、岗位关闭、重复发送及发送快照等规则。这些检查不代表真实模型效果或生产系统验证。

## GitHub Pages 部署

仓库已包含 `.github/workflows/pages.yml`。上传到 GitHub 后，在仓库 **Settings → Pages → Source** 选择 **GitHub Actions**，推送 `main` 或手动运行工作流，即可部署 `dist/`。

## 文件结构

- `dist/index.html`：页面入口
- `dist/styles.css`：界面样式
- `dist/core.js`：模拟案例、匹配规则和状态校验
- `dist/app.js`：界面渲染和交互
- `test-core.cjs`：核心逻辑检查
- `serve.mjs`：本地静态服务
- `docs/screenshots/`：真实页面截图

## 边界

当前版本用于产品经理笔试和作品集展示；未接入 EHR、真实岗位数据、邮件服务或后台权限系统。生产落地还需要服务端鉴权、权限隔离、幂等发送、审计以及模型离线和在线评测。
